# Product Requirements Document

## The Lenny Growth Assistant

### Overview

The Lenny Growth Assistant is a full-stack AI conversational application that helps users access and apply insights from Lenny's Podcast and Newsletter. The application provides RAG-grounded answers with traceable citations, supports artifact generation, and offers a dedicated Ship 30 for 30 writing skill.

### Key Features (Planned)

1. **RAG-Grounded Conversation** — Answer questions using Lenny's podcast/newsletter transcripts with traceable citations
2. **Multi-Provider LLM Support** — Anthropic Claude (cloud) and Ollama (local) inference
3. **Agent Layer** — Built on the Anthropic Claude Agent SDK
4. **Artifact Generation** — Markdown and HTML/CSS artifacts rendered in a safe in-app viewer
5. **Ship 30 for 30 Writing Skill** — Dedicated writing assistance workflow
6. **Session Persistence** — Conversations persisted in PostgreSQL
7. **Structured Logging** — Observable and debuggable application behavior
8. **Health and Readiness Checks** — Production-grade operational endpoints
